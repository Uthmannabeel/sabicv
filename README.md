# SabiCV

**AI career agent for Nigerian job seekers.** Upload your CV, paste the job
you want — SabiCV's AI agent analyses the gap, rewrites your CV to fit, writes
a tailored cover letter, and delivers polished PDFs in minutes. Pay per order
via Paystack.

Built for the [Build with Gemini XPRIZE](https://xprize.devpost.com)
(deadline 2026-08-17), category **Professional Services Access**: a real
business operated by AI agents, with real customers and real revenue, powered
by the Gemini API on Google Cloud.

## How it works

1. Customer uploads their current CV (or fills a guided form) and pastes the
   target job description.
2. The agent parses the CV, scores it against the job, and plans the rewrite.
3. Payment via Paystack unlocks generation.
4. The agent rewrites the CV, writes the cover letter, renders PDFs, and
   delivers them by download link and email.
5. Every agent decision is logged per order (XPRIZE agent-execution evidence).
